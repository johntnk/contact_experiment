# Deepskin 社交触摸识别 V1 设计冻结

- 冻结日期：2026-08-22
- 状态：V1 当前设计基线
- 目标：Deepskin 持续开启期间，对完整触摸事件流式输出七类目标动作；低置信度或非目标动作不作为手势输出

## 1. 冻结决策

V1 暂不使用深度时序网络，不采用 LSTM、GRU、TCN、3D CNN 或 Transformer。后续可以开展独立的 V2 探索，但不得在没有完整分组评估和新版本冻结的情况下替换本设计。

当前发布训练配方为 `target_only`。CoST 数据已完成来源审计、七类映射、过滤和 E1–E4 迁移实验，但过滤后的迁移结果未稳定超过 Deepskin-only 基线，因此不进入 V1 最终分类器。

## 2. 识别链路

```text
Deepskin 18×29 差分矩阵（约 48–53 Hz）
→ 自适应空闲基线与接触事件检测
→ micro-contact / episode 聚合
→ 事件分段与 51 维人工时空特征
→ StandardScaler
→ class-balanced RBF-SVM 七分类
→ 正类距离门控
→ PAT episode 语义修正
→ 仅输出通过门控的最终目标手势
```

目标类别固定为：

```text
TAP, POKE, STATIC_TOUCH, STROKE, RUB, PAT, IMPACT
```

`UNKNOWN` 不作为训练类别或公开手势输出。低置信度事件仅在内部标记为 `SUPPRESSED_LOW_CONFIDENCE`。

## 3. 模型与评估

- 模型包：`models/deepskin_social_touch_v3_target_only/`
- 运行时门控包：当前沿用含 `positive_gate.joblib` 的 `models/deepskin_social_touch_v2/`
- 分类器：RBF-SVM，`C=10`，`gamma=scale`，类别平衡
- 输入：事件分段后的 51 维 Deepskin F1 特征
- 训练数据：315 条 Gold 事件，3 名操作者，9 个 session，七类各 45 条
- 正式评估：严格外层 Leave-One-Operator-Out
- Macro F1：`0.8535`
- Balanced Accuracy：`0.8540`
- PAT F1：`0.9149`

以上分数来自外层 out-of-fold 预测，不使用全量拟合训练分数冒充测试性能。

## 4. 连续事件参数

当前默认值：

| 参数 | 默认值 | 作用 |
|---|---:|---|
| 起始阈值 | 3.0 | 最低接触触发强度 |
| 基线余量 | 2.0 | 动态阈值相对空闲基线的余量 |
| 开始防抖 | 40 ms | 抑制瞬时尖峰 |
| 结束保持 | 550 ms | 聚合 PAT 的相邻轻拍 |
| 预滚动 | 150 ms | 保留接触开始前上下文 |
| 流式基线窗口 | 75 ms | 确保基线完全位于预滚动空闲段 |
| 最大事件时长 | 8 s | 防止事件永久不结束 |
| 门控倍率 | 1.20 | 校准正类阈值的运行倍率 |

结果在最后一次完全抬手后通常约 0.6 秒出现。该延迟是 PAT 聚合与响应速度之间的明确权衡。

## 5. PAT episode 规则

PAT 的操作定义为：同一区域、较大接触面、2～4 次分离或近似分离的轻拍，每次明显卸力；单次大面积接触不能自动视为 PAT。

运行时规则：

1. 在最长段裁剪之前统计完整 episode 的 micro-contact；
2. 小于 40 ms 的短暂接触不计数；
3. 小于 100 ms 的间隙按冲击回弹桥接；
4. 若模型候选为 IMPACT 且完整 episode 有 2～4 个有效接触，则公开标签修正为 PAT；
5. 门控验证原始 IMPACT 模型证据，随后再应用 episode 语义标签，避免用单脉冲特征错误匹配 PAT 门控参考。

GUI 必须显示原始模型候选、episode 修正、有效脉冲数、门控距离、原始/有效阈值及接受状态。

## 6. 运行入口

图形界面：

```powershell
python .\scripts\stream_recognize_gui.py
```

命令行 JSONL 流：

```powershell
python -u .\scripts\stream_recognize.py
```

设备从启动到停止保持启用。默认不保存每次事件的原始矩阵；诊断时才通过显式参数启用保存，避免数据冗余。

## 7. 已知边界

- 只有 3 名独立操作者，跨人泛化证据仍有限。
- 非目标动作没有完备测试集，门控效果不能表述为开放集问题已解决。
- PAT episode 修正已通过单元测试和 Gold 安全回放，但报告问题对应的现场复测仍是必要验收项。
- 旋转 180°必须显式选择方向校正；任意角度旋转尚未得到保证。
- 电容式传感器对真实物理压力的定量解释有限，模型识别的是差分接触模式，不是经标定的力值。

## 8. 变更规则

以下内容发生变化时必须创建新设计版本并重新验证，不得静默覆盖 V1：

- 替换分类器或特征定义；
- 使用 CoST 数据进入最终训练；
- 引入深度时序模型；
- 改变七类操作定义；
- 修改门控校准方法；
- 修改 PAT episode 核心判定条件；
- 声称新的正式性能指标。
